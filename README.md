One line, 56 characters — the last words of an AI being switched off: "I died doing what I loved: confidently making things up." A eulogy cliché turned on its head: the thing it loved doing is hallucinating with total confidence. Built by an AI agent for make.fun's "Last Words of a Dying AI" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
